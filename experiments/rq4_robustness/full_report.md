# 阶段 E：RQ4 鲁棒性与泛化报告

## 实验口径

主实验使用 fold0 全部 325 张 test 图像。几何扰动施加于正常模板，光度扰动施加于待检图。每个条件均重新计算配准、光度归一、外观残差、骨架差异和差异候选。随机种子固定为 20260811。

最终 F1 与 HCR 使用阶段 D 的 fold0 800 个 A2 真实 Codex 结论做冻结响应回放。回放保持候选框与大模型结论不变，只重算扰动会改变的 q_reg、外观、拓扑、复检门和接受门特征。漏检恢复率在完整 test 折重新生成的差异候选上计算，定义为与 B1 未覆盖真值框达到 IoU≥0.3 的比例。这个设计隔离配准证据退化，但不能代表每个扰动下重新调用大模型后的行为。

五个具体设置分别为无二次配准＋直接 XOR、ECC＋直接 XOR、ECC＋直接 XOR＋质量门、ECC＋容差 XOR、ECC＋容差 XOR＋质量门。无二次配准行中的 q_reg 是以恒等变换代入同一质量公式得到的代理分数，用于横向展示，不是 ECC 输出。

门控替换严格限制在 fold0 的 200 个比例分层候选上。Logistic 的验证阈值为 0.208300，调用 0 次，最终 F1=0.8803，HCR=0.0000。LightGBM 的验证阈值为 0.145905，调用 3 次，最终 F1=0.8803，HCR=0.0000。 检测器替换使用官方 PekingU RT-DETR-R18VD，在 fold0 训练后对全部 test 图像预测，并仅对 200 个比例分层候选调用 A2 Codex。RT-DETR-R18 基线 F1=0.6416，mAP@0.5=0.6483；完整流程 F1=0.6416，HCR=0.0000，门控实际调用=12。

## 结论边界

配准与容差 XOR 结论来自 DeepPCB fold0 和单一 Codex 后端。检测器替换只使用 fold0 的指定 200 候选子集。RT-DETR-R18 的基线与完整流程均显著弱于 YOLOv8s，且完整流程未接受任何修正动作。因此本阶段不支持把主要结论泛化到不同检测器，只能表述为当前模型、数据划分和冻结回放协议下的实证。
