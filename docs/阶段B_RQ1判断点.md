# 阶段 B：Prompt 调整与小规模真实 RQ1 报告

## 实验设置

Prompt 固定为 `prompt_v2`。诊断集从五折 test 候选按四类和折号分层抽取 150 个，随机种子为 20260811。原始漏检候选与漏检真值采用 IoU ≥ 0.3 的阶段 A 候选恢复口径，差异噪声要求与全部真值 IoU < 0.3。四个配置均复用同一批候选，后端为 `codex_cli`，模型为 `gpt-5.6-sol`，温度配置为 0，4 路并发，共 600 次候选判断。该平衡诊断集不用于推断部署时的自然分布性能。

Prompt v2 优先判断缺陷存在性和 normal，参考不可靠时要求 uncertain，并仅对 DIFF 候选加入基础检测器未提出该区域的独立判断提示。动作映射仍保留类别输出，但 relabel 必须同时满足预测类别与模型自报拓扑一致、模型自报拓扑与检测器类别典型拓扑矛盾。Prompt 依据 train 折错误分解确定，测试集结果未用于继续调参。

## 结果解读

A2 的存在性 F1 为 0.8082，高于 A6 的 0.7763，因此本实验支持显式参考证据相对单裁剪有价值，但不支持证据数量与性能单调递增。A3 的 uncertain 率为 0.3267，明显高于 A2 的 0.1067；A6 加入拓扑差异与数值拓扑后 uncertain 率回落到 0.1133，说明单独加入外观差异会引入冲突，而结构证据能部分恢复判断稳定性。

在 DIFF 来源上，存在性 F1 从 A0 的 0.3922 提升到 A6 的 0.7324，支持 add 路径的候选级判断能力。A6 六类 Macro-F1 为 0.3136，与 A2 的 0.3153 接近且绝对值仍低，说明本轮主要收益来自缺陷存在性判断，不应扩大为细粒度类别识别已经充分解决。

## 判断结论

主判据预先固定为 A6 相对 A0 的缺陷存在性 F1 提升。提升 ≥ 0.10 时，核心假设成立并进入全量 RQ1；提升在 0.03 到 0.10 时，核心假设成立但偏弱，应缩小宣称并把重心转向双门控的成本收益；提升 < 0.03 时，核心假设不成立，需要降级题目。

本次 A0 F1 为 0.5920，A6 F1 为 0.7763，提升为 +0.1843。因此，**核心假设成立，进入全量 RQ1**。

次判据预先固定为 A6 在原始 FP 候选上的 normal 判定率。若低于 0.3，remove 路径基本不可用。

本次该比例为 0.6579。因此，**remove 路径具备可用性**。

本报告按预先固定的 prompt_v2 一次性评估，没有依据测试结果调整 prompt 或重跑以改善数字。
